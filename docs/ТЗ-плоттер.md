# Раздел «Плоттер» — рулонная печать (ТЗ, черновик)

Ветка: `feature/plotter` (отдельный клон `KopiTehnik-Print-plotter`, от main после PR #17). Сначала логика без Qt (`plotter_layout.py`, тесты), потом окно.

## Задача
Третий режим рядом с «Фото» и «Документ»: печать готовых файлов на рулон плоттера (пример: HP DesignJet Z5200, 44"). Пользователь выбирает ширину рулона, получает поле этой ширины, кидает на него файлы, расставляет и поворачивает их как хочет, задаёт зазор в сантиметрах. Длина рулона не вводится: считается по нижнему краю самого дальнего файла. Потом одна кнопка «Печать».

Главное требование пользователя: **точно видеть размеры всех файлов и иметь возможность их править.**

## Рулоны
Стандартные ширины (мм): 297 (A3), 420 (A2), 432 (17"), 594 (A1), 610 (24"), 841 (A0), 914 (36"), 1067 (42"), 1118 (44"). Z5200 принимает рулоны 279–1118 мм. Список выбора плюс «Своя ширина» (число в мм/см). Ширину «45/600/600/1100» из исходного сообщения читаю как 432/610/914/1118; уточнить у пользователя, какие рулоны реально стоят.
Печатная ширина меньше рулона на непечатаемые кромки (по умолчанию 5 мм с каждой стороны; берётся из драйвера через `printer_geometry`, иначе из настройки). Поле показывает и ширину рулона, и печатную зону.

## Поле раскладки
- Масштаб «в реальных сантиметрах»: линейки сверху и слева, сетка по 1/5/10 см, прокрутка по длине вниз, колесо — масштаб.
- Файлы (ответ пользователя: Photoshop, обычные JPEG и популярные форматы для печати чертежей):
  - Растр: JPG/JPEG, PNG, TIFF (в т.ч. многослойный и большой), BMP, WEBP.
  - Photoshop: PSD и PSB (слитое изображение; библиотека `psd-tools` или чтение композита), с учётом ICC-профиля и физического размера из метаданных.
  - Чертежи: PDF (любой размер листа, векторный рендер на нужный DPI, выбор страницы), далее DXF/DWG и HPGL/PLT: в первой версии через конвертацию в PDF внешним средством, если оно установлено (иначе подсказка, как экспортировать); отдельно проверить с пользователем, какие именно форматы нужны (DWG, PLT, TIFF от сканера).
  - Перетаскивание на поле и кнопка «Добавить». У каждого файла берётся физический размер из метаданных (DPI/размер листа PDF), его можно править в панели. Каждый файл — рамка с превью.
- Перемещение мышью и стрелками (шаг 1 мм, Shift — 1 см), поворот на 90° (клавиша R, кнопка), произвольный угол в панели, отражение, дубликат (копии), удаление.
- Привязка (вкл/выкл): к краям печатной зоны и к соседним файлам с учётом зазора, подсветка направляющих.
- Выделение несколькими файлами, выравнивание по левому/правому краю, центр, равные интервалы.
- Длина рулона = нижний край самого нижнего файла + нижнее поле. Показывается постоянно: «Длина: 2,34 м, площадь 2,6 м²».
- Зазор между файлами в см (по умолчанию 1,0) — один параметр на раскладку; также зазор от краёв. «Применить зазор» сдвигает файлы, нарушающие его; предупреждение красной рамкой, если файлы ближе зазора или перекрываются или выходят за печатную зону.

## Точные размеры и правка (обязательное)
1. Подписи на поле у каждого файла: ширина × высота в см (например «60,0 × 42,3 см»), при выделении ещё и размеры до краёв и до соседей.
2. Панель свойств выбранного файла: ширина, высота, X, Y (от левого края печатной зоны и от начала рулона), поворот, масштаб %, эффективный DPI, исходный размер в пикселях. Единицы переключаются: см / мм / дюймы.
3. Все поля редактируются цифрами. Замок пропорций (по умолчанию включён): правка ширины пересчитывает высоту и наоборот. Кнопки: «Подогнать по ширине рулона», «Исходный размер при N dpi», «Размер по метаданным файла».
4. Предупреждение при DPI ниже порога (по умолчанию 100 dpi для плоттера, настраивается) и при масштабировании больше ширины рулона.
5. Таблица всех файлов внизу: имя, размер в см, повороты, копии, DPI; сортировка, включение/отключение файла из печати, суммарная длина.
6. Отмена/повтор (Ctrl+Z / Ctrl+Y) всех действий над раскладкой.

## Авторасклад
Кнопка «Расставить»: упаковка прямоугольников (MaxRects / skyline) с учётом зазора, поворота на 90° (флажок «разрешить поворот»), цель — минимальная длина рулона. Режимы: «Минимум длины», «В порядке списка», «Столбцом по ширине рулона». Результат можно сразу править руками. Показывает экономию («Было 3,1 м, стало 2,4 м»).

## Печать
1. Профиль принтера как в режиме «Документ»: принтер, цветокоррекция, ICC, поправка принтера, повторное использование `print_profiles`.
2. Лист = рулон нужной печатной ширины и вычисленной длины. Бумага задаётся пользовательским размером через `pc.devmode_write(blob, {"paper_mm": [W, L]})`; у некоторых драйверов нужно сначала выбрать «Рулон» как источник бумаги.
3. Ограничение: `dmPaperLength` — 16-битное в 0,1 мм, максимум 3276,7 мм (≈3,27 м). Для более длинных раскладок: предупреждение и разбиение по горизонтальному резу (с пометкой «часть 1/2», опция «внахлёст N мм») либо печать несколькими заданиями. Нужно проверить на реальном Z5200, не поднимает ли HP-драйвер лимит иначе.
4. Память: рулон 1118×3000 мм при 300 dpi ≈ 13200×35400 пикселей (≈1,4 ГБ RGB). Рендер лист-полосами: `PrinterJob.page` принимает одну картинку, поэтому нужно добавить полосный режим (рендер каждой полосы из файлов по месту), DPI печати по умолчанию 150–300, выбор в панели.
5. Предпечатный отчёт: ширина, длина, площадь, число файлов, DPI, предупреждения; подтверждение «Начать печать?».
6. Прогресс по полосам, «Отмена», запись в `print_stats` (kind="plotter", площадь в м²).
7. Предпросмотр «как напечатается» (с профилем и поправкой) — вторым этапом.

## Архитектура
- `plotter_layout.py` (без Qt): модели `Item`, `Layout`, единицы, расчёт длины, проверки (перекрытие, зазор, выход за поле), упаковка, сохранение/загрузка JSON, undo-стек. Покрыт тестами `tests/test_plotter_layout.py`.
- `plotter_ui.py`: `PlotterView` (QGraphicsView: поле, линейки, рамки файлов, привязки), панель свойств, таблица файлов.
- Интеграция в `photo_crop_qt.py`: `ModeSwitch` из двух пунктов превращается в три («Фото», «Документ», «Плоттер»), `set_app_mode("plot")`, страница «Плоттер» справа, `print_now` для `plot` вызывает `print_plotter()`.
- Переводы: ключи в `i18n*.py`, русский — источник.

## Этапы
1. `plotter_layout.py` + тесты (единицы, длина, зазор, упаковка, сохранение).
2. Окно: поле, добавление, перемещение/поворот, панель размеров, длина.
3. Печать: полосный рендер, пользовательская бумага, предупреждение >3,27 м.
4. Авторасклад, метки реза, `.kplot`, переводы, документация, README/RELEASE_NOTES.

## Открытые вопросы пользователю
1. Печать идёт через обычный драйвер Windows (HP DesignJet Z5200) или через RIP?
2. Какие форматы файлов бросаете на плоттер: растровые (JPG/TIFF) или ещё PDF/чертежи?
3. Какие рулоны реально стоят (432/610/914/1118)?
4. Максимальная длина одной раскладки обычно: до 3 м или больше?
5. Нужны метки реза и подписи?

## Что должен проверить пользователь на реальном плоттере
- Пользовательский размер бумаги нужной ширины и длины принимается драйвером без обрезки по краям.
- Реальные размеры отпечатка равны размерам на экране (измерить линейкой).
- Длинные раскладки (>3 м) и нагрузка на память.
