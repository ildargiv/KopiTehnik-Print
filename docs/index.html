Let an AI run the job

set_format10×15 and others
auto_cropsmart frame
set_adjustcolour
plan_printsheet layout
preflightcheck before printing
printsend to printer

The agent takes JSON commands through a command line, and an MCP server lets Claude Desktop drive the whole program. Add it to your Claude Desktop config and ask for the prints in plain words.

// claude_desktop_config.json
{
  "mcpServers": {
    "photocrop": {
      "command": "C:\\path\\to\\PhotoCropAgent.exe",
      "args": ["mcp"]
    }
  }
}
