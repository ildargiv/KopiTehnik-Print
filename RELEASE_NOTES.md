# Release notes — v1.0.0 (first release)

First public release of PhotoCrop (КопиТехник PRINT).

- Qt interface (`PhotoCropQt.exe`) and the older Tkinter window (`photo_crop.py`).
- Cropping and printing for 10×15 cm and other formats up to A2.
- Smart crop (faces, people, pets), per-photo colour correction, printer ICC profile.
- Print planning with pre-print checks, per-side bleed, one job per sheet.
- AI-agent mode and MCP server (`PhotoCropAgent.exe mcp`).
- Interface languages in the Qt version: Русский, English, 日本語, 한국어, Türkçe, Bahasa Indonesia, العربية, हिन्दी, Italiano, Polski, Українська, Tiếng Việt, ไทย, 繁體中文, Татарча; the translations are machine-made and not yet reviewed by native speakers.
- Detection models are downloaded on first use. License: not selected.

Files in the release: `PhotoCropQt.exe`, `PhotoCropAgent.exe`.
