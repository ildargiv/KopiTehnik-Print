# Release notes — v1.2.0

- **One program with a built-in AI agent (MCP).** The agent works inside the program's own window: it sees and changes the same photos, frames, colours and print settings you do, and you watch it live (Ctrl+Z undoes its steps). Full rights including printing; limits (no printing, sheet limit) are optional in Settings. While the agent works the window is view-only, with a button to take control back.
- **Installer** (`KopiTehnikPrint-Setup-*.exe`) with an option to connect the agent to Claude Desktop. The agent can also be connected to Claude Code, Cursor, Windsurf, OpenCode, OpenClaw, Hermes, VS Code and other clients from Settings.
- **New agent tools:** mirror photos, white balance by a reference point, list ICC profiles, batch of commands, contact sheet, before/after comparison and a table of statistics for a whole series. The agent works by hand (frames, levels, curves) and does not use the automatic buttons unless asked.
- **Print profiles.** Colour profile, driver settings and sharpness are remembered per printer + sheet size + paper type and applied automatically.
- **Sheet by frame size** (as many frames as fit), Fit/Crop choice, three colour **Presets** you can rename, white balance eyedropper, mirror buttons.
- **Enhance / Super** now use levels, curves and selective colour and reset the photo's earlier correction first.
- **New look:** dot-matrix logo and program icon, animated agent badge, settings as a tree, folder previews in the Open window, the first tab is now **Layout**. Confirmations for routine actions are off by default (can be turned on in Settings). The duplicate dashed "trim" frame was removed; trimming is set on the Printer tab.
- **About** section with version, author, GitHub link and update check. License: PolyForm Noncommercial 1.0.0 (free for personal and non-commercial use).

Files in the release: `PhotoCropQt.exe`, `KopiTehnikPrint-Setup-1.2.0.exe`.
