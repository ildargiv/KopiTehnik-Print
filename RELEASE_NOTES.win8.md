# KopiTehnik Print for Windows 8 / 8.1 (separate build)

A build for older Windows (Python 3.8, Qt 5). It is a separate file: `KopiTehnikPrint-Win8-<version>.exe`, no installer. On Windows 10 and 11 use the regular release.

What is different from the regular version:

- No "Document" section (PDF, Word, Excel preview and printing).
- No printing on several printers at once.
- "Smart frame" (AI) works only if the AI runtime starts on your system; otherwise the rest of the program works as usual.

Everything else (cropping, colour, layout, printing on one printer, Quick Start, Epson driver controls, AI agent MCP) is the same as in the regular version of the same number.

Не поддерживается: раздел «Документ» и печать на нескольких принтерах. «Умная рамка» работает, только если ИИ-модуль запускается на вашей системе.
