# Заметки о выпуске — v1.2.0

- **Одна программа со встроенным ИИ-агентом (MCP).** Агент работает в самом окне программы: видит и меняет те же фото, рамки, цвета и настройки печати, что и вы, а вы видите это вживую (Ctrl+Z отменяет его шаги). Полные права, включая печать; ограничения (запрет печати, лимит листов) по желанию задаются в настройках. Пока агент работает, окно только для просмотра, есть кнопка «Забрать управление».
- **Установщик** (`KopiTehnikPrint-Setup-*.exe`) с пунктом «Подключить агента к Claude Desktop». Агента можно подключить и к Claude Code, Cursor, Windsurf, OpenCode, OpenClaw, Hermes, VS Code и другим программам из настроек.
- **Новые инструменты агента:** отражение фото, баланс белого по эталону, список ICC-профилей, пакет команд, контактный лист, сравнение до/после и таблица статистики по всей серии. Агент работает вручную (рамки, уровни, кривые) и не использует автоматические кнопки без просьбы.
- **Профили печати.** Цветовой профиль, настройки драйвера и резкость запоминаются для каждой связки принтер + размер листа + тип бумаги и подставляются сами.
- **Лист по размеру рамки** (сколько рамок влезет), выбор «Кадрировать / Вписать», три **пресета** цвета с переименованием, пипетка баланса белого, кнопки отражения.
- **«Улучшить» и «Супер»** теперь работают через уровни, кривые и выборочный цвет и сначала сбрасывают прежнюю коррекцию фото.
- **Новый вид:** точечный логотип и значок программы, анимированная плашка агента, настройки деревом, превью папок в окне «Открыть», первая вкладка теперь **Макет**. Подтверждения обычных действий по умолчанию выключены (включаются в настройках). Дублирующая пунктирная рамка подрезки убрана, подрезка задаётся на вкладке «Принтер».
- Раздел **«О программе»**: версия, автор, ссылка на GitHub, проверка обновлений. Лицензия: PolyForm Noncommercial 1.0.0 (бесплатно для личного и некоммерческого использования).

Файлы выпуска: `PhotoCropQt.exe`, `KopiTehnikPrint-Setup-1.2.0.exe`.
