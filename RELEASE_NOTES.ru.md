# Заметки о выпуске — v1.8.0

- **Сеть: автопоиск и простое подключение**: программа сама находит другие копии в локальной сети (и онлайн-ПК Tailscale). Нажмите «＋» в чате, выберите найденный ПК и нажмите «Подключить»: у вас появятся 6 цифр, их нужно ввести в окне запроса на том ПК. Три неверных кода отменяют запрос. Адрес можно ввести вручную, если ПК не нашёлся.
- **Печать на другом ПК**: кнопка 🖧 рядом с «Печать» (появляется, когда подключённый ПК в сети): выбираете ПК и его принтер, листы собираются у вас, печатаются с цветом и настройками драйвера того ПК. Бумага в драйвере там должна совпадать с форматом листа.
- **Раздел «Сеть» в настройках**: включение сети, приём печати, имя, папка для файлов, список ПК (переименовать, скрыть, запретить печать, забыть, версия программы), какие принтеры отдавать по сети.
- Внизу справа кнопки состояния подключённых ПК (цвет: в сети, печатает, нужно внимание, нет в сети); клик открывает чат. Кнопка 🖼 в чате отправляет отмеченные фото. В чате строки «напечатано» или «сбой печати», статус доставки сообщений, очередь неотправленного сохраняется при перезапуске.
- Безопасность: обмен кода по схеме с паролем (6 цифр нельзя подобрать по перехваченному трафику, три ошибки отменяют запрос), id и роли в подписи, лимиты на подключения и запросы, подмена адреса через UDP не действует, вторая копия программы не занимает порт, правило брандмауэра в установщике (для установки от администратора).
- **Принтеры**: у каждого принтера можно задать своё имя и скрыть ненужные (кнопка ✎ рядом со списком принтеров, в окне «Принтеры для печати» и в настройках, раздел «Печать → Принтеры»). Скрытые не показываются в списках печати.
- Сеть теперь включена по умолчанию (при первом запуске Windows может спросить разрешение для брандмауэра: разрешите для частной сети). Соединение по-прежнему не шифруется; 6-значный код защищает от случайных подключений в доверенной сети, для открытых сетей используйте Tailscale.

Файлы релиза: `KopiTehnikPrint-Setup-1.8.0.exe`, `KopiTehnikPrint-Portable-1.8.0.exe`.

# Заметки о выпуске — v1.7.0

- **Сеть (новое)**: соединение нескольких копий программы по локальной сети или Tailscale. Спаривание ПК по одноразовому коду; панель чата слева (текст, смайлики, любые файлы; фото показываются картинкой с кнопкой «Скачать»; звуки можно выключить) и основа для печати на принтере другого ПК (лист готовится на вашем ПК, печатается с цветовым профилем и настройками драйвера принимающего ПК). Сеть выключена, пока вы не подключите первый ПК; соединение проверяется ключом пары, но не шифруется (используйте доверенную сеть или Tailscale).
- Состояние принтеров, выбор удалённого принтера в окне печати и кнопки состояния подключённых ПК в окне пока не добавлены.

Файлы релиза: `KopiTehnikPrint-Setup-1.7.0.exe`, `KopiTehnikPrint-Portable-1.7.0.exe`.

# Заметки о выпуске — v1.6.1

- **ИИ-агент (MCP)**: новые инструменты `multi_print` (принтеры, ячейка «Быстрого старта» для каждого, режимы «блоками» и «по одному», допечатка), `zoom_photo` (процент, «Поместить», заполнить, оригинал) и `crop_apply` («Обрезать» по рамке в подпапку «Обрезанные»). При нескольких отмеченных принтерах `print_photos` раздаёт листы между ними.
- **Переводы**: английский для всех строк, добавленных в 1.5–1.6 (несколько принтеров, быстрый старт, Epson, увеличение и обрезка); основные подписи на остальных языках интерфейса (машинный перевод, носителями языка не проверялся).
- Портативный файл теперь называется `KopiTehnikPrint-Portable-<версия>.exe`.
- Папка данных теперь `%APPDATA%\KopiTehnik Print`; старая папка `PhotoCrop` (настройки, проекты, журналы, модели) переносится туда при первом запуске.
