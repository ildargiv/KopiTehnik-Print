# Проект КопиТехник PRINT (PhotoCrop)

Десктопная программа на Python для кадрирования и печати фотографий (форматы 10x15 и другие). Версия 1.8.0.

Исходники: `C:\Users\User\Desktop\Программы\KopiTehnik-Print`. Git используется.

## Файлы проекта

|---|---|

Зависимости зафиксированы в `requirements.txt`.

## Сборки

- `PhotoCrop.exe` и `PhotoCropAgent.exe` — версия на Tkinter; `PhotoCropAgent.exe` — консольный агент для MCP.
- `PhotoCropQt.exe` — Qt-версия.

Пользователь работает с Qt-версией.

## ИИ-агент

Команды: `open_folder`, `set_format`, `auto_crop`, `set_crop`, `set_adjust`, `select_printer`, `plan_print`, `render_sheet`, `preflight`, `print` и др. (полный список в `AGENT.md`).

## Отложено пользователем

1. Судьба старых exe: перенести в `История\` или удалить.
2. Поддержка Windows 8 (Qt6): решение отложено до конца разработки.
