# Фирменный стиль КопиТехник Принт

Принятый логотип: **«Дата-штамп»** (точечная матрица 5×7 как дата на плёнке). Кадр на кромке плёнки и в знаке: **27**.

| Что | Где в коде |
|---|---|
| Название и знак (RU и EN) | `brand_datestamp.py` |
| Анимированный логотип «LED-табло» (интро, покой, наведение, клик) | `logo_anim_led.py` (классы `LogoMarkAnim`, `BrandTitleAnim`) |
| Плашка «ИИ-агент работает» (вариант «Нейросеть») | `agent_badge_neural.py` |
| Значок окна и панели задач | `make_app_icon()` в `photo_crop_qt.py` |

Файлы в этой папке: `wordmark_{ru,en}_{dark,light}.png`, `mark_{512..16}_{dark,light}.png`, `app_icon.ico` / `app_icon_256.png`,
`animation/` — кадры анимаций. Цвета: оранжевый `#ff8a1e`, фон `#17181c`, светлый фон `#f4f4f6`.
