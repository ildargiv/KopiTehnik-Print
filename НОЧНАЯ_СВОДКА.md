# Ночная сводка (авто-режим) — обновлено под утро 22.10

## ГЛАВНОЕ: «Без полей» ВЗЛОМАНО ✅
Флаг найден через окно свойств драйвера (DocumentPropertiesW + DM_IN_PROMPT, галку
поставили и ОК нажали скриптом реальными кликами мыши). Разница DEVMODE «до/после» —
всего 3 байта (`dmsnaps\prompt_in.bin` vs `prompt_out.bin`):

| Где | До → После | Смысл |
|---|---|---|
| публ. offset 88 `dmDefaultSource` | 261 → **262** | безполейная печать только через лоток 262 |
| приват. +7700 (байт 7920) | 0x20 → **0x21** | сам флаг «Без полей» (bit 0) |
| приват. +7768 (байт 7988) | 0x00 → 0x39 | код бумаги без полей: 0x39=A4, **0x36=10×15** — драйвер считает САМ при merge |

Рецепт включения (проверен round-trip on/off, CreateDC даёт offset 0.0 мм,
область = весь лист):
1. `dmDefaultSource = 262`
2. приват. байт +7700 `|= 0x01`
3. прогнать через `DocumentPropertiesW` mode `8|2` — драйвер сам допишет +7768
4. **сохранить в реестр** `HKCU\Printers\DevModePerUser`, значение = имя принтера.
   SetPrinter(level 92) Epson отвергает (ошибка 124, и с GlobalAlloc тоже) — реестр работает,
   DocumentProperties подхватывает сразу, перезапуск шпулера не нужен.

### Готовые команды (в `epson_dmcfg.py`)
```
python epson_dmcfg.py border status   # текущее состояние + область печати
python epson_dmcfg.py border on      # без полей (весь лист)
python epson_dmcfg.py border off     # обычные поля 3 мм
python epson_dmcfg.py ccor status    # режим цветокоррекции драйвера
python epson_dmcfg.py ccor on        # «Настройка» = драйвер цвет НЕ правит
python epson_dmcfg.py ccor off       # «Автоматический» (заводской режим)
```
(пишут в HKCU\DevModePerUser для «EPSON L8050 Series (копия 1)»;
backup прежнего значения: `dmsnaps\reguser_backup.bin`, версия «без полей A4»: `reguser_border_on.bin`)

## ЦВЕТОКОРРЕКЦИЯ ДРАЙВЕРА: отключена ✅ (утро)
- Во вкладке драйвера «Дополнительные настройки» группа «Цветокоррекция»:
  радиокнопки «Автоматический» / «Настройка». Тот же трюк (окно драйвера → клац → ОК → diff
  DEVMODE): режим лежит в **приватном байте +188: 01=«Автоматический», 02=«Настройка»**.
  В «Настройке» при нейтральных подстройках (а они нейтральны — diff молчит) драйвер
  НЕ перекрашивает картинку. Это аналог «No Color Adjustment» — обязательная вещь,
  т.к. приложение уже само профилит фото в ICC EPSON Photo Glossy (иначе двойная коррекция).
- Применено везде: реестр (дефолт копии), настройки приложения (settings.json),
  пресет «10x15 без полей», файл проекта и **профили печати** в окне программы
  («10×15 | Глянцевая фотобумага» и «…Простая бумага»). `priv+188=02` во всех носителях.
- **Важный нюанс:** настройки драйвера живут в 4 местах (реестр / settings.json / проект /
  пресет) и их держат в памяти 2 процесса программы (GUI и mcp-мост). Правки файлов
  при работающей программе перетираются её памятью — поэтому программа была перезапущена
  (закрыта, файлы пропатчены, открыта заново; проект загружен). Мосты-«зомби» от прежнего
  запуска убиты; связь агента с программой (photocrop MCP) после этого требует переподключения
  (перезапуск OpenCode или новой сессии) — на саму печать из окна это не влияет.
- Откат: `python epson_dmcfg.py ccor off` + перезапуск программы (или снять выбор
  «Настройка» в окне свойств драйвера).

## Что это дало в приложении «КопиТехник-Print»
- Оказалось, DEVMODE самого приложения (лоток 262) уже содержал флаг 0x21 — реальные
  задания на печать уходят **уже без полей** (снимки очереди `jobpriv_plain_2/3.bin`).
- Preflight врал из-за другого: в print_options бумага стояла «custom 152×102» —
  Epson для произвольного размера (DMPAPER_USER) безполейную печать НЕ делает, всегда 3 мм.
  Переставил бумагу на **«Как в драйвере принтера»** (форма 285 = 10×15, 101.6×152.4 мм).
- **preflight: ready=true**, все 12 фото помещаются, ошибок нет.
- Сохранено: проект `Новая папка 10x15\проект 10x15.json` (бумага=driver, blob с флагом)
  и пресет **«10x15 без полей»** (принтер + print_options + driver settings — загружается за секунды).
- Текущее состояние: border по умолчанию = **ON** (для копии принтера; обычный «EPSON L8050
  Series» не тронут). Откат: `border off`.

## На работе — как печатать
1. Если там тот же L8050 и этот ПК: пресет «10x15 без полей» → print (или сначала
   1 лист). Прогнать `border on` не помешает (проверить `border status`).
2. Если принтер другой / неясно: печатать PDF из папок (там страницы = 10×15 ровно)
   с настройкой «без полей» в его драйвере, либо нести JPEG в фотосалон.
3. Профиль EPSON L8050 встроен в файлы — на другом принтере это слегка исказит цвет;
   для фотосалона лучше сказать «печать без цветокоррекции» или доэкспортировать без ICC.

## Технические заметки (чтобы не повторять грабли)
- DocumentPropertiesW Epson: DM_OUT_BUFFER=**2**; IN=NULL с IN_BUFFER падает — подавай тот же буфер.
- SetPrinterW 92 → err 124 всегда (даже родной devmode). Путь — HKCU\Printers\DevModePerUser.
- SendMessageW(BM_CLICK) окну свойств драйвера вешает поток; реальные mouse_event работают.
  Галка «Без полей» всплывает модальное предупреждение («качество сверху/снизу…») — жать его OK.
- CreateDC/GetDeviceCaps НЕ реагируют на произвольные байты приватной зоны — geometry-пробинг
  бесполезен (3986 проб, 0 хитов). Только diff «до/после» реального ОК.
- Двойная коррекция цвета: приложение уже конвертит в ICC L8050 (icm_off=true).
